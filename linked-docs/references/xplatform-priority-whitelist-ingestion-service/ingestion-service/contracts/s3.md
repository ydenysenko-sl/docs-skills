# S3

Buckets ingestion-service writes via presigned URL and reads during validation. Per-environment bucket; objects laid out by date.

## playson-priority-whitelist-{env}

Per-region bucket holding uploaded whitelist CSVs.

### **Own** whitelists/{YYYY}/{MM}/{DD}/{priority_whitelist_id}.csv

CSV upload payload for one priority whitelist.

Payload — [PriorityWhitelistCsv](../objects/PriorityWhitelistCsv.md):
- one row per player; columns per CSV schema doc

Lifecycle: bucket rule deletes objects after 30 days. ACL: bucket-private; access via presigned URL (PUT) or service IAM role (GET).
