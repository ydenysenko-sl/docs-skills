# Pet

JPA entity. Child of [Owner](Owner.md). One pet belongs to exactly one owner; one owner has many pets. Looked up by api-gateway when assembling an owner-details page and by visits-service when validating visit requests.

## Fields

**id** — int (auto-increment), required
  PK. Generated by MySQL.

**name** — string (1..30), required
  Pet name.

**birthDate** — date (ISO 8601), required
  Year-month-day of birth.

**type** — PetType, required
  Many-to-one to `types` lookup (`cat` / `dog` / `bird` / ...). Eager-fetched.

**owner** — Owner, required
  Many-to-one back-reference to [Owner](Owner.md). FK `owner_id`. Hidden from JSON via `@JsonBackReference`.
