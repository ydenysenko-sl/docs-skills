# Owner

JPA entity. Parent of [Pet](Pet.md). Persisted in MySQL via Spring Data; mutated through REST writes and read by the api-gateway aggregator.

## Fields

**id** — int (auto-increment), required
  PK. Generated by MySQL.

**firstName**, **lastName** — string (1..30), required
  Owner name.

**address** — string (1..255), required
  Postal address line.

**city** — string (1..80), required
  City of residence.

**telephone** — string (1..20, digits), required
  Contact number. Validated by `@Digits`.

**pets** — Pet[], lazy
  One-to-many — see [Pet](Pet.md). Mapped on `owner_id` FK; fetch strategy `LAZY`.
